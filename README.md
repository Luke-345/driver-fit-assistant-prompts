# Driver Fit Assistant – Prompt Development

ARIN 121 Final Project.

**Driver Fit Assistant** is an AI application that helps beginner to mid-handicap golfers choose a driver without paying for a professional fitting. It asks about the golfer's height, swing speed, ball flight, usual miss and budget one question at a time, then recommends a starting driver setup (loft, head type, shaft flex and weight, length, grip) with a reason for each, a shortlist of real driver models within budget, and a checklist for testing in a shop.
